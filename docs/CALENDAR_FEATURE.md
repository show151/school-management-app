# 📅 カレンダー機能

全ユーザーがアクセスできる、課題管理用のカレンダービューです。

## アクセス方法

### URL直接アクセス
```
http://localhost:3000/dashboard/calendar
```

### ダッシュボードから
1. ダッシュボードページにアクセス
2. 「課題の状況」セクションの「📅 カレンダー」ボタンをクリック

### タスク一覧ページから
1. タスク一覧ページにアクセス
2. 右上の「📅 カレンダー」ボタンをクリック

## 機能詳細

### 📆 カレンダー表示
- **月単位表示**: 前月・当月・次月の日付を含む6週間表示
- **曜日色分け**: 日曜日（赤）、土曜日（青）
- **今日ハイライト**: 今日の日付は青いリングで囲まれる
- **月移動ボタン**: 「← 前月」「今日」「次月 →」で簡単に移動

### 📝 タスク表示
- **未完了タスクのみ**: 完了済みタスクは自動的に非表示
- **ドット表示**: 各日付にタスクがある場合は色付きドット（●）で表示
- **色で緊急度を表示**:
  - 🔴 **赤**: 期限切れまたは今日が締切
  - 🟠 **オレンジ**: 明日が締切
  - 🟡 **黄色**: 2〜3日以内が締切
  - 🔵 **青**: 4日以上先が締切
- **最大3ドット表示**: 4件以上の場合は「+N」で件数表示
- **日付タップ**: 日付をタップするとその日のタスク一覧モーダルが開く

### 🔍 タスク一覧モーダル
日付をタップすると、その日のタスク一覧モーダルが開きます：

**表示情報**
- 日付（曜日付き）
- 未完了タスクの件数
- 各タスクの詳細（教科、課題名、締切、補足）
- 緊急度バッジ（今日、明日、あとN日、期限切れ）

**操作**
- チェックボックスで完了/未完了を切り替え
- 「完了」「戻す」ボタンでも操作可能
- 「閉じる」ボタンまたはモーダル外クリックで閉じる

### ⚡ リアルタイム更新
- タスクを完了にすると即座にカレンダーから消える
- 未完了に戻すと即座にカレンダーに表示される

## 利用シーン

### 週次計画
```
今週の課題を確認して、計画的に取り組む
例: 月曜日に数学、水曜日に英語、金曜日に理科
```

### 期末前の確認
```
期末テスト前に未完了の課題を一覧で確認
カレンダービューで視覚的に把握しやすい
```

### 締切管理
```
月末にどれだけの課題があるか一目で確認
余裕を持って取り組むための計画に活用
```

## 技術仕様

### データソース
- API: `/api/tasks` (GET)
- フィルタ: `isCompleted = false` のタスクのみ表示

### 状態管理
- タスク更新: `/api/tasks` (PUT)
- ローカル状態で即座にUIを更新

### デザイン
- レスポンシブ対応（モバイル・タブレット・PC）
- 既存デザインシステムと統一
- CSS変数を使用したテーマ対応

### セキュリティ
- middlewareによる認証保護
- ログインユーザーのみアクセス可能
- 自分のタスクのみ表示・操作可能

## UI要素

### カラーパレット
```css
--primary: #4f46e5 (インディゴ) - ドット（4日以上先）、今日のハイライト
--background: #f0f7ff (薄いスカイブルー) - ページ背景
--card: #ffffff (白) - カレンダーセル背景
--border: #cbd5e1 (グレー) - セルの境界線
```

### ドット表示と緊急度
- タスクがある日付には色付きドット（●）を表示
- 最大3つのドットを表示
- 4件以上の場合は「+N」と件数を表示
- **色の意味**:
  - `#dc2626` (赤): 期限切れ・今日締切
  - `#ea580c` (オレンジ): 明日締切
  - `#ca8a04` (黄色): 2〜3日以内
  - `#4f46e5` (青): 4日以上先
- 複数タスクがある日は、最も緊急度の高いタスクの色で表示
- タスクのない日付にはドットなし

### レスポンシブ
- **PC**: 7列グリッド、各セル80px以上
- **タブレット**: 7列グリッド、各セル70px程度
- **モバイル**: 7列グリッド、各セル50px程度（縦スクロール）
